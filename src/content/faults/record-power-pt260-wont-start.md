## The symptom pattern

Press the switch and nothing happens — not a stutter, not a trip, just no
motor. On a machine like the PT260 that's disconcerting precisely because
there's no fault code and no obvious moving part to blame. The machine looks
ready to run and simply doesn't.

## What's actually happening

The PT260 won't start unless three separate safety microswitches are all
closed at once, and Record Power's own support guidance sets out exactly
what closes each one. In their words: "When using the PT260 in order for
microswitches to register, completing the electrical circuit and therefore
allowing the machine to start the dust extraction hoods must be in place."

In planing mode, the table has to be locked down with both handles
activating the first switch, and the dust extraction hood correctly fitted
underneath the table to activate the second. Switch to thicknessing mode and
a third switch takes over: "make sure that the swing over dust extraction
outlet is fully covering the cutter block thus activating the 3rd
micro-switch." Miss any one of the three for whichever mode you're in, and
the circuit stays open — the machine isn't broken, it's refusing to start
with a guard or the table not properly in position, which is exactly what an
interlock is for.

## Working through it

Go through the three in order rather than assuming which one's wrong. Check
both table locking handles are fully engaged first — a table that's only
partly locked can look secure without actually closing the switch. Then, for
planing, check the dust hood is seated correctly under the table rather than
just resting near it. For thicknessing, check the swing-over outlet has gone
all the way over the cutter block — it's easy to leave it part-swung after
changing modes, and a partial swing looks fine at a glance but won't close
the switch.

Record Power's guidance is direct about the outcome: "If these guidelines
are followed the safety microswitches should present no problems when using
the machine." That's worth taking at face value — this is a setup problem in
the large majority of cases, not a machine fault.

## The fix

There's no repair here in the ordinary case — relock, reseat, or reswing
whichever of the three isn't closed, and the machine starts. If table, hood
and outlet are all genuinely correct and it still won't run, the fault has
moved past what Record Power's setup guidance covers: a microswitch itself
has failed, or there's a wiring fault in the interlock circuit. That's not
something to chase by working on live switches on a planer-thicknesser, and
it's not something to bypass to get the machine running in the meantime —
the switches are there because the cutter block underneath is exposed the
moment a guard is out of position. Get it looked at properly.

## Verdict

Free, in order: table lock, dust hood, swing-over outlet. That clears the
overwhelming majority of "PT260 won't start" cases without a call-out or a
part. A genuine microswitch or wiring fault behind that interlock is
uncommon but real, and it's worth an electrician's or Record Power's time
rather than yours on a machine built around an exposed blade.
